# Panel UI screenshots

Screenshots for the stacked pull requests that change the Nerve web panel.

All images come from a throwaway Nerve instance with made-up data (for example
`alice`, `bob`, `example/repo`, `example.com`). No image shows a real instance.
The PR descriptions link to these files at a fixed commit.

File names: `<view>-<before|after>-<dark|light>-<desktop|phone>.png`.
"Before" is main; "after" is the branch of the PR.
